## About 📖

HWMonitor is a long running hardware monitoring tool developed by CPUID, the same team behind CPU-Z. It reads sensor data exposed by your motherboard, processor, graphics card and storage drives, then displays it in a nested list grouped by device. Typical readings include CPU core temperatures, package power, motherboard and chipset temps, fan RPM, voltage rails, GPU thermals and SSD or HDD temperatures where SMART data is available. The 2026 build refreshes CPU and GPU support, improves sensor detection on recent chipsets and keeps the portable mode for users who prefer to run it from a folder without a full install.

If you came looking for a HWMonitor download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. Everything on this page is written for desktop Windows users who want a quick read on thermals before a heavy workload or during normal use.

**Good for:** PC builders checking cooling · overclockers watching temperatures under load · system integrators validating builds · laptop owners tracking thermal throttling · IT staff doing quick health checks · enthusiasts logging fan curves · anyone curious what their sensors report.

## Features 🔑

| | |
|---|---|
| 🌡️ **Live temperatures** | Per core CPU temps, package temp, motherboard and chipset sensors in real time. |
| 🌀 **Fan speed monitoring** | Reads RPM values from connected case, CPU and GPU fans where a tach signal is present. |
| ⚡ **Voltage rails** | Displays the +3.3 V, +5 V and +12 V lines plus VCore and memory voltages. |
| 🔋 **Power draw** | Package power, GPU board power and per rail wattage on supported hardware. |
| 💾 **Storage health** | Temperature and basic SMART attributes for SATA and NVMe drives. |
| 📈 **Min and max tracking** | Every row keeps the lowest and highest value seen since launch. |
| 🖥️ **GPU sensors** | Core temperature, hotspot, memory junction and fan speed for modern cards. |
| 📂 **Portable mode** | Run from a USB stick or folder without touching the registry. |
| 💽 **Save and load reports** | Export the current sensor tree to a text file for later comparison. |

## Troubleshooting 🛠️

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Sensors show as N/A | Update your motherboard chipset drivers, most sensor reads depend on the SMBus driver. |
| Fan speed missing for some headers | Not every header exposes a tach signal, check your board manual for which ones report RPM. |
| Readings look stuck | Close the app, then reopen it so the sensor list is rebuilt from scratch. |
| GPU temperature absent | Update your graphics driver, older drivers may not expose the thermal sensor. |
| App does not start after install | Reboot once, then launch again from the Start menu with no other monitoring tools running. |
| Values change too quickly to read | Enable min and max tracking, then run your workload and compare the retained values. |
